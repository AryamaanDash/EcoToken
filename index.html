Data quality

What these numbers mean

01

Routing is measured

Prompt counts and selected tiers are recorded after the local router returns a decision.

02

Cost is estimated

Cost avoided uses configured per-token model rates and the same estimated token volume for both models.

03

Carbon is estimated

CO₂ avoided uses 0.01, 0.05, and 0.40 kWh per million tokens for Lite, Flash, and Pro, with a 400 g CO₂e/kWh grid factor.

Gemini’s website does not expose billing usage or energy-meter data to this extension. Cost and carbon values are modeled estimates using the stated benchmarks—not an invoice, meter reading, or verified emissions claim.
